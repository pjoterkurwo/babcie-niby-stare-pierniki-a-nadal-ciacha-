# Piękno Dojrzałości

Strona internetowa dedykowana pamięci, mądrości i sile dojrzałych kobiet.

### Funkcje:
- Interaktywna galeria z podglądem lightbox.
- Możliwość dynamicznej podmiany zdjęcia metodą Drag&Drop, wyborem pliku lub wklejeniem ze schowka (`Ctrl+V`).
- Księga podziękowań zapisująca wpisy lokalnie w przeglądarce (`localStorage`).
- Generator inspirujących cytatów.
